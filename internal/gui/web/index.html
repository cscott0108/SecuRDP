5. Dynamic DNS (DuckDNS) — optional

Gives your home a name like myhome.duckdns.org that follows your public IP, so saved computers never need editing when your ISP changes it. The SecuRDP service checks every 5 minutes and updates DuckDNS when the IP changes.

  1. Go to duckdns.org and sign in (Google, GitHub, etc.).
  2. Type a name under sub domain and click add domain.
  3. Copy the token shown at the top of that page and paste both below.

How it works

    
The PC you connect to runs the SecuRDP service on one port. You log in with username, password and a Google Authenticator code. Only then does it carry your Remote Desktop session, encrypted inside SSH, to this PC's own Remote Desktop. Nothing else on your network is reachable through it.

Connecting from another computer

    
    
      
  1. Copy securdp.exe to that computer and run it (no admin needed).
    2. 
      
  2. Connect tab → Add computer: your home public IP (or a dynamic DNS name), the gate port, your username.
    3. 
      
  3. Click Connect, then enter your password and the current code from Google Authenticator.
    4. 
      
  4. The first time, compare the fingerprint with the one you wrote down.
    5. 
      
  5. Remote Desktop opens. Tick Remember me in its login box if you want Windows to save that PC's login. Each saved computer keeps its own.
    6. 
      
  6. Closing Remote Desktop closes the tunnel.
    7. 
    

    
Tip: the first time, Remote Desktop may warn that the certificate name doesn't match (it sees 127.0.0.x). That's expected with a tunnel. Tick "Don't ask me again" for that computer.
