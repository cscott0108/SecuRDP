# Project Name: SecuRDP

A single Windows executable (`securdp.exe`) that is an SSH-gated Remote Desktop gateway: the **service** on a server/hub PC authenticates with password + TOTP (Google Authenticator) and then only forwards to approved RDP targets; the **client** (same exe, plus an Android app) opens the SSH tunnel and launches Remote Desktop through it. User-facing docs: `README.md`.

## 🛠️ Build & Run Commands
*   **Install Dependencies:** `go mod download` (Go 1.26 — `go.mod` pins `toolchain go1.26.10`; if an older Go is installed set `GOTOOLCHAIN=go1.26.10`). Android: Gradle wrapper fetches everything; needs Android SDK (platform 35) and **JDK 21** (`$env:JAVA_HOME="C:\Program Files\Eclipse Adoptium\jdk-21.0.9.10-hotspot"`).
*   **Run Development Server:** `go run . gui` (native WebView2 window) or `go run . gui --no-open` (prints a tokenised `http://127.0.0.1:<port>/?t=…` URL for a browser). Server-side UI needs an elevated process. `go run . serve` runs the gate in the console (admin; uses the real `C:\ProgramData\SecuRDP` config — see Rules).
*   **Build Project:** `.\build.ps1` → runs `go run ./tools/mkres` (icon/manifest/version → `rsrc_windows_amd64.syso`), `go test ./...`, then `go build -trimpath -ldflags "-s -w" -o securdp.exe .`. Android: `cd android; .\gradlew.bat assembleRelease` → `android\app\build\outputs\apk\release\app-release.apk` (copied to `SecuRDP.apk`).
*   **Run Tests:** `go test ./...`. Android: `cd android; .\gradlew.bat testDebugUnitTest` (live tests auto-skip if no gate). Full Android e2e: start a throwaway two-PC hub with `SECURDP_SERVE_ADDR=127.0.0.1:38999 go test ./internal/server -run TestServeForExternalClient` (users `probe.user`/`probe.two`, password `Test-passphrase-123`, TOTP secret `JBSWY3DPEHPK3PXP`), then add `-Dsecurdp.e2e.port=38999`.

## 📂 Architecture & Key Paths
*   **Entry Point:** `main.go` — dispatches `gui` (default) / `tray` / `connect` / `install` / `uninstall` / `serve` / `status` / `version`; runs as the Windows service when started by the SCM.
*   **Source Code:** `internal/` (Go), `android/app/src/main/java/app/securdp/` (Kotlin).
*   **Components/Modules:**
    *   `internal/server` — SSH gate: keyboard-interactive auth (password + TOTP), IP banning, hub routing (`user+computer` login suffix, `list.securdp` computer list, named direct-tcpip destinations checked against the user's allow-list), tunnel grace timer, Wake-on-LAN.
    *   `internal/client` — tunnel client (`Connect` → `Computers` → `Listen`), `.rdp` file generation, CLI connect.
    *   `internal/gui` — loopback HTTP API (token + Host check) + embedded web UI in `internal/gui/web/` (vanilla JS/CSS, CSP `'self'`), shown via go-webview2.
    *   `internal/service` — Windows service install/update/migration, tray scheduled task, installed-version check.
    *   `internal/tray` — Win32 notification-area icon; window "show" signalling via a named event.
    *   `internal/config` — server/client JSON config, DPAPI secret protection, folder ACLs, computers/roles model.
    *   `internal/auth` (Argon2id, TOTP, limiter), `internal/ddns` (DuckDNS updater), `internal/netinfo` (public IP), `internal/winutil` (firewall, RDP registry, elevation), `internal/logx`, `internal/version` (**single version source**).
    *   `tools/mkres` — draws the icon in code; writes the `.syso`, web `icon.png` and Android launcher icons.
    *   Android: `Tunnel.kt` (JSch + Bouncy Castle, pure JVM, unit-testable), `TunnelService.kt` (foreground service + state), `MainActivity.kt` (Compose UI), `Profiles.kt`.
*   **Configuration Files:** `go.mod`; `android/app/build.gradle.kts` (`versionCode`/`versionName`); runtime: `C:\ProgramData\SecuRDP\server.json` (+ `hostkey`, `securdp.log`, `ddns-status.json`; SYSTEM/Admins only), `%APPDATA%\SecuRDP\client.json`; secrets: `android/keystore.properties` + `android/securdp-release.jks` (git-ignored).

## 🎨 Code Style & Tech Stack
*   **Stack:** Go 1.26 (golang.org/x/crypto/ssh, x/sys/windows, go-webview2, go-qrcode), Windows 10/11 only; vanilla HTML/CSS/JS UI; Android Kotlin 2.0 + Jetpack Compose (Material 3), AGP 8.13, minSdk 26 / target 35, JSch (mwiede) + Bouncy Castle.
*   **Formatting:** `gofmt`; Kotlin official style. Match the surrounding code: short doc comments explaining *why*, no frameworks in the web UI, no external CDNs (CSP blocks them). Prefer the standard library; ask before adding dependencies.
*   **Rules:**
    *   Never edit generated/build output: `securdp.exe`, `*.apk`, `android/app/build/`, `android/.gradle/`. `rsrc_windows_amd64.syso` and Android `ic_launcher_foreground.png` files are generated by `tools/mkres` — change `tools/mkres` instead.
    *   Never commit or print the signing key or its passwords (`*.jks`, `keystore.properties`). Release APKs must keep using that key or installed apps can't update.
    *   **Don't touch the live install** without the user's explicit OK: don't write `C:\ProgramData\SecuRDP`, restart/install/uninstall the `SecuRDP` service, or change firewall rules — the user may be connected remotely through it. Tests use a temp `ProgramData` with `config.LockServerDir = false`, or the in-process test gates.
    *   Bump the version in `internal/version/version.go` (Windows) and `versionCode`/`versionName` (Android) for each release.
    *   Keep the security model: the gate only ever forwards to configured targets; new capabilities are opt-in, per-user, allow-listed and logged.
    *   Commits end with the Co-Authored-By trailer; run `go test ./...` (and Android unit tests when touched) before committing.
